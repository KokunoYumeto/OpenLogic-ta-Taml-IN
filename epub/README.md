# தமிழ் EPUB வாசிப்பு நூல்கள்

இந்த EPUB 3.3 நூல்கள், தமிழ்ப் PDF வாசிப்பு நூல்களின் திரையளவுக்கு ஏற்ப மாறும் இணைப் பதிப்புகள். அதே மொழிபெயர்க்கப்பட்ட TeX முதன்மைக் கோப்புகளிலிருந்து உருவாக்கப்படுகின்றன. ஒரே முழு EPUB 722 மூல அலகுகளையும் கொண்டுள்ளது; அதன் முதன்மைப் பகுதியில் 695 அலகுகளும் பெயரிடப்பட்ட இணைப்பில் மற்ற 27 அலகுகளும் உள்ளன. இவை 695/27 அலகுகளாகத் தனித்த EPUB நூல்களாகவும் வழங்கப்படுகின்றன. கணித வாய்பாடுகள் PDF பக்கப் படங்களாக அல்லாமல் TeX4ht உருவாக்கும் MathML ஆக வழங்கப்படும்.

TeX இலிருந்து XHTML உருவாக்க `build/build-epub-html.ps1` ஐப் பயன்படுத்துக. `make4ht` செயல்முறை முழுவதும் `Global\InterlanguageTeXSlotV1` பாதுகாப்புப் பூட்டுக்குள் நடைபெறும்; அதன் சான்று களஞ்சியத்திற்கு வெளியே பதியப்படும். பின்னர் `package_epub.py` XHTML கோப்புகளைச் சீரமைத்து, மூல அலகு பொருத்தப் பட்டியலை உருவாக்கி, மீளுருவாக்கக்கூடிய தனித் EPUB நூல்களை எழுதும். இரண்டும் தனித்தனியாகச் சரிபார்க்கப்பட்ட பிறகு `python build/assemble-complete-722-epub.py` அவற்றின் உள்ளடக்கத்தை ஒரே EPUB-இல் முதன்மை நூல்/இணைப்பு என்ற வரிசையில் இணைக்கும். `audit_epub.py` ZIP அமைப்பு, நூல் வரிசை, மொழிக் குறி, வழிசெலுத்தல், MathML, மூல அலகுக் கணக்கு, உள்ளக இணைப்புகள் ஆகியவற்றைத் தனியாகச் சரிபார்த்து EPUBCheck 5.3.0 ஐ இயக்கும்.

Python தொகுப்பியின் சார்புகளை `python -m pip install -r epub/requirements.txt` மூலம் நிறுவுக. பழைய TeX4ht உருவாக்கும் HTML5, உடைந்த கணிதத் துணுக்குகள் மற்றும் தவறான MathML குறிகளைத் தொகுப்பி சீர்செய்து, தனித்த கணித வாய்பாடுகளையும் தமிழ்த் தொடருரையையும் வாசிப்பு வரிசையில் வைக்கிறது. மூல-EPUB பொருத்தப் பட்டியல் 722 அலகுகளின் முழுமையையும் PDF-இல் உண்மையில் காணப்படும் தமிழ்ச் சொற்கள் EPUB-இல் இருப்பதையும் சரிபார்க்கிறது. மூல TeX இன் தேர்ந்தெடுக்கப்படாத நிபந்தனைக் கிளைகளில் உள்ள சொற்கள் வாசிப்பு நூலுக்குரியவை அல்ல; அவற்றின் வேறுபாடுகளும் சான்றில் பதியப்படுகின்றன. தனி EPUBCheck கோப்பின் வடிவச் செல்லுபடியைச் சரிபார்க்கிறது. `pdftotext` மற்றும் EPUBCheck 5.3.0 இயக்குநிரலும் தேவை.

இயல்பான மாற்றி LuaLaTeX உடன் `tex4ht`; `-Engine xelatex` மூலம் XeLaTeX-ஐத் தேர்ந்தெடுக்கலாம். இக்கணினியில் உள்ள பழைய TeX4ht பதிப்பிற்காக உருவாக்கப்படும் EPUB மாற்றுக் கோப்பில் மட்டும் `\partokencontext=0` அமைக்கப்படுகிறது; நிறுவல் மரங்களின் படங்களுக்குத் தேவையான பத்தி முடிவும் சேர்க்கப்படுகிறது. தமிழாக்க மூலமும் சரிபார்க்கப்பட்ட PDF-களும் இதனால் மாறுவதில்லை. விருப்பமான `lua4ht` மாற்றியைப் பயன்படுத்துவதற்கு முன் `kpsewhich lua4ht.sty` அதன் நிறுவலை உறுதிப்படுத்த வேண்டும்; இல்லாவிட்டால் எந்த TeX செயல்முறையும் தொடங்குமுன் `backend-unavailable` சான்றில் பதியப்படும்.

முதன்மை EPUB-க்கான மாற்று, 11 மூலக் கோப்புகளிலுள்ள 65 அடுக்குக் குறிகளின் கட்டளை-உருப்படிகளுக்கு கணிதப் பொருள் மாறாத அடைப்புக்குறிகளைச் சேர்க்கிறது. இன்னொரு தனி அடுக்குக் குறிக்கும் அதே சீரமைப்பு செய்யப்படுகிறது. பழைய TeX4ht-இல் `align*` உள்ளே தோல்வியுறும் இரண்டு நிறுவல் மரங்கள், வரிசையும் முடிவுகளும் மாறாமல் தனித்த மையப்படுத்திய SVG படங்களாக உருவாக்கப்படுகின்றன. இவை அனைத்தும் `epub/work/` இல் உருவாகும் தற்காலிகக் கோப்புகளில் மட்டுமே நடைபெறும்; ஒவ்வொரு மூலமும் மாற்றுக் கோப்பும் கொண்ட SHA256 கட்டமைப்புச் சான்றில் பதியப்படும்.

சரிபார்ப்புக் கருவியின் பாதையை `--epubcheck-jar PATH` ஆகக் கொடுக்கலாம் அல்லது `EPUBCHECK_JAR` சூழல் மாறியில் அமைக்கலாம். கருவி இம்மூலத் தொகுப்பில் மறுவெளியிடப்படவில்லை.
