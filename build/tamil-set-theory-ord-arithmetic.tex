\chapter*{திறந்த தருக்கவியல்}
\noindent தமிழ் மொழிபெயர்ப்பு — வரிசையெண் எண்கணிதம்

\noindent மூல ஆசிரியர்கள்: Open Logic Project.
\href{https://github.com/OpenLogicProject/OpenLogic}{மூல நூல்},
\href{https://creativecommons.org/licenses/by/4.0/}{CC BY 4.0}.
இந்தப் பிரதி OpenAI Codex — GPT-6 Sol, Ultra முயற்சி நிலையில்
இயந்திர மொழிபெயர்க்கப்பட்டு கணிதப் பொருள் ஒப்பீடு செய்யப்பட்டது.
சுயாதீன மனிதச் சரிபார்ப்பு செய்யப்பட்டதாகக் கூறப்படவில்லை.
முழுப் பதிப்பு இன்னும் தயாராகவில்லை.

\noindent இந்தத் தனித்த வாசிப்புப் பிரதியில் 722 உறையவைக்கப்பட்ட மூல
அலகுகளில் OLP-0574 முதல் OLP-0579 வரையிலான 6 அலகுகள் இடம்பெறுகின்றன.
வரிசையெண் கூட்டல், கணங்களின் தரநிலைக் கணக்குகள், பெருக்கல் மற்றும்
அடுக்கேற்றம் விவாதிக்கப்படுகின்றன.
\emph{பதிப்புக் குறிப்பு:} ஆங்கில மூலத்தில் கண்ட ஏழு உள்ளூர்
குறியீட்டு மற்றும் கணிதத் தவறுகள் TA-STH-023--029 என்ற தனித்த
மூலத் திருத்தப் பதிவில் விளக்கப்பட்டுள்ளன.
